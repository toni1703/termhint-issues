# Security

Please don't open a public issue for a vulnerability in Termhint. Report it privately:

- [Report a vulnerability](https://github.com/toni1703/termhint-issues/security/advisories/new)
  here (only the maintainer sees it), or
- write to hello@termhint.com.

Include the Termhint version (in the header of the panel under the menu-bar icon), your macOS
version, what an attacker needs and gains, and steps to reproduce. Leave real secrets, keys and
personal data out.
